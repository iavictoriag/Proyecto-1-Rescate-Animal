#Sistema de Rescate Animal

Este es el proyecto de software se trata de una aplicación de escritorio pensada para facilitar y organizar el trabajo diario en un centro de rescate animal.

## ¿Qué puedes hacer con esta aplicación?

* **Registrar animales y rescates:** Mantén el control de cada ingreso con validaciones automáticas de códigos.
* **Administrar espacios de refugio:** Asigna áreas específicas (como perros), revisa su estado (disponible/ocupado) y guarda la información de forma segura.
* **Gestionar adopciones:** Lleva el registro de los solicitantes y el proceso de vinculación con las mascotas.
* **Generar reportes y bitácora:** Visualiza reportes rápidos del sistema y consulta el registro de actividades en la bitácora.

## Tecnologías 
* **Lenguaje:** Java (JDK 17)
* **Interfaz Gráfica:** Java Swing (NetBeans GUI Forms)
* **Persistencia:** Archivos de texto plano (`.txt`)
* **Control de versiones:** Git y GitHub
